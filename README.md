# Programación Orientada a Objetos (POO) 🚀

Repositorio oficial para las prácticas, estructuras de control y ejercicios lógicos en Java.

## 📂 Contenido del Proyecto
* **Sentencias de Decisión**: Ejercicios de condicionales, validadores y operadores lógicos.
* **Bucles y Ciclos (`for`, `while`)**: Contadores, acumuladores, series numéricas y promedios.
* **Interfaces Gráficas (Swing)**: Clases unificadas para la ejecución rápida de toda la lógica.

---
*Desarrollado para cumplir con los requerimientos de la materia de forma rápida y funcional.* 👨‍💻
